    Dieses Dokument ist ein Produkt von Claude, der KI von Anthropic. Es ist die Java-Portierung des Kurses „C# 14 lernen mit .NET 10“ (Oktober 2026), der seinerseits eine Neufassung des Kurses „Apprentissage du langage C# 3.0 / .NET 3.5“ ist, den Serge Tahé im Mai 2008 verfasst hat. Es behält Gliederung, Beispiele und roten Faden bei und schreibt sie in modernem Java neu:

    • das Dokument verwendet Java 25 (September 2025), die aktuelle Version mit Langzeitunterstützung (LTS) von Java, und stellt in den einzelnen Kapiteln die Neuerungen der Sprache vor – von den kompakten Quelldateien in Java 25 bis zu den virtuellen Threads in Java 21, einschließlich Records, versiegelter Klassen und Pattern Matching;
    • wo sich die beiden Sprachen unterscheiden, übersetzt das Dokument nicht einfach: Eigenschaften, Strukturen, Operatorüberladung und Delegates von C# gibt es in Java nicht; Java hat dafür eigene Lösungen (Getter, Records, funktionale Interfaces); umgekehrt kennt Java Konzepte, die nur ihm eigen sind, wie Checked Exceptions und virtuelle Threads; diese werden ausführlich behandelt;
    • zwei Kapitel setzen einen anderen Schwerpunkt: die asynchrone Programmierung, die Java mit den Klassen [CompletableFuture] und virtuellen Threads statt mit den Schlüsselwörtern [async] / [await] löst, und das objektrelationale Mapping, das Hibernate bereitstellt, der am weitesten verbreitete ORM der Java-Welt;
    • die Bibliotheken sind die, die heute in Java üblich sind: [JUnit 6] für Tests, [Spring Framework 7] für Dependency Injection, [Jackson 3] für JSON, der Treiber [MySQL Connector/J] für JDBC, [Hibernate 7] und [Spring Boot 4] für Webservices; die Projekte werden mit [Maven] erstellt.

    Dieses Dokument ist kein umfassender Kurs. Wie die Kurse, aus denen es hervorgegangen ist, richtet es sich an Personen, die bereits programmieren können und die Grundlagen von Java erlernen möchten. Es arbeitet mit Beispielen: mehr als zweihundert Programme (mehr als dreihundert Java-Dateien), die meisten davon kurz und Zeile für Zeile kommentiert.

    1.1. Java von 1995 bis 2026

    Java wurde im Mai 1995 von Sun Microsystems veröffentlicht. Es beruht auf einer Idee, die für seinen Erfolg entscheidend war: Der Compiler [javac] erzeugt keinen Maschinencode, sondern einen Zwischencode – den Bytecode –, der in [.class]-Dateien gespeichert wird und den die Java Virtual Machine (JVM, „Java Virtual Machine“) ausführt, indem sie ihn zur Laufzeit in Maschinencode übersetzt. Ein einziges kompiliertes Programm läuft so unter Windows, Linux oder macOS: „write once, run anywhere“. Auch die Sprachen Kotlin, Scala und Groovy erzeugen Bytecode und nutzen dieselben Bibliotheken.

    Wichtige Meilensteine:

    • 2006–2007: OpenJDK. Sun veröffentlichte den Java-Quellcode unter einer Open-Source-Lizenz (JDK). Alle heutigen Java-Distributionen werden aus OpenJDK erstellt;
    • 2010: Oracle übernimmt Sun und wird zum wichtigsten Beitragenden zu Java;
    • 2014: Java 8, eine bahnbrechende Version: Lambda-Ausdrücke, Stream-API, die neue Datums- und Zeit-API. Viele Programme im Produktivbetrieb sind noch in diesem Stil geschrieben;
    • Seit 2017 (Java 9): Alle sechs Monate, im März und im September, erscheint eine neue Java-Version. Einige Versionen haben Langzeitunterstützung (LTS, „Long-Term Support“): Java 11 (2018), 17 (2021), 21 (2023) und 25 (September 2025), die in diesem Dokument verwendet wird; seit Java 17 erscheint alle zwei Jahre eine neue LTS-Version. Die übrigen Versionen werden nur sechs Monate lang unterstützt; neue Funktionen erscheinen oft zunächst als „Previews“, bevor sie in einer späteren Version endgültig übernommen werden;
    • Das JDK wird von mehreren Anbietern vertrieben, die alle auf OpenJDK beruhen und für unsere Zwecke gleichwertig sind: Oracle, die Eclipse Foundation (Eclipse Temurin, Projekt Adoptium), Microsoft, Amazon (Corretto) und die Linux-Distributionen.

    Die kleinen Programme sind kompakte Quelldateien: eine einzelne Datei mit der Endung [.java], die mit dem Befehl [java File.java] ausgeführt wird (Kapitel 2). Programme aus mehreren Dateien, die nur die Bibliotheken des JDK verwenden, werden auf dieselbe Weise gestartet. Programme, die eine externe Bibliothek benötigen (Jackson, JUnit, Spring, der MySQL-Treiber, Hibernate, Spring Boot), sind Maven-Projekte ([pom.xml]).

    Alle Programme dieses Dokuments wurden vom Compiler [javac] des JDK 25 ohne Fehler und ohne Warnungen kompiliert, und zwar mit der Option [-Xlint:all], die alle Warnungen aktiviert, und mit den im Anhang aufgeführten Bibliotheksversionen ausgeführt. Die in diesem Dokument abgedruckten Ergebnisse stammen aus diesen Ausführungen. Die Ergebnisse der Kapitel 2 bis 4 wurden mit den französischen Sprach- und Ländereinstellungen (fr-FR) erzielt, wie auf einem französischen Windows-System: Formatierte Gleitkommazahlen werden mit Dezimalkomma angezeigt, und Datumsangaben erscheinen auf Französisch; die folgenden Kapitel wurden mit englischen Einstellungen ausgeführt (Dezimalpunkt, englische Datumsangaben). Zwei Anmerkungen:

    • die Fehlermeldungen des JDK (Meldungen von Exceptions, Compilermeldungen) sind auf Englisch: Das JDK stellt dafür keine französische Übersetzung bereit;
    • die Beispiele wurden unter Linux ausgeführt. Meist macht das keinen Unterschied: Java ist plattformunabhängig. Die wenigen Unterschiede (Dateipfade mit / statt \, Terminalbefehle) werden an der jeweiligen Stelle erwähnt.

    Die Ergebnisse von Multithreading-, asynchronen oder Netzwerkprogrammen sowie die gemessenen Ausführungszeiten können sich von einer Ausführung zur nächsten unterscheiden: Die Kommentare konzentrieren sich auf das, was reproduzierbar ist.
